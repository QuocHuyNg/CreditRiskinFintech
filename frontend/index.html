About the Model

Technical details and methodology

psychology

HistGradientBoosting

A high-performance gradient boosting algorithm inspired by LightGBM, built into scikit-learn. It handles missing values natively and is optimized for large datasets.

speed

Probability of Default

The model outputs a probability (0–1) of a borrower experiencing serious delinquency (90+ days late) within 2 years, converted to the 300–850 credit score scale.

swap_vert

Score Conversion

Uses the standard banking formula: Score = Offset − Factor × ln(PD / (1−PD)) with Base Score = 600 and PDO = 50 (points to double the odds).

gpp_good

Model Validation

Validated on 30,000 held-out samples. KS = 0.58 indicates excellent separation between good and bad borrowers. Gini = 0.74 confirms strong discriminatory power.
